# Premature P0 fielding machinery — filed 2026-07-28

> **⚠️ ARCHIVED — not active direction.** These documents were built ahead of
> the decision they were meant to serve. Retained for history; do not field
> from here without re-deciding whether P0 should run at all and in what form.

## Why these were filed

The four files in this directory (`OUTREACH_DRAFTS.md`,
`P0_RECRUITMENT.md`, `P0_RECRUITMENT_TEMPLATES.md`,
`P0_RECRUITMENT_TRACKER.md`) constitute a complete, ready-to-send recruitment
+ screening + tracking pipeline for P0 user-validation sessions.

They were built while the project's core value proposition to writers is
**still unproven** — and while the fielding decision itself (whether, when, and
with what signal rule to run P0) had not been made by a decision owner. That is
the definition of getting ahead of the work: a polished fielding kit waiting at
zero-recruited does not move the gate; only the human decision to field, and
the human act of recruiting, does.

Per the project's own constitution (`NORTH_STAR.md`: *demand before rigor*),
maintaining active recruitment machinery before the decision to field is a form
of premature rigor. It has been filed, not deleted, so the work is recoverable
the moment a decision owner re-opens P0 fielding.

## What to do instead, if/when P0 is re-opened

The **authoritative P0 protocol** (`docs/user-validation/P0_OPERATING_KIT.md`)
is self-contained on recruitment — it specifies eligibility, neutral-invitation
rules, consent, and privacy without depending on any file in this directory.
The decision owner should:

1. Decide whether to field P0 at all, and on what signal rule (ROADMAP §3 is
   qualitative; the kit declines to set a numerical threshold).
2. Re-read the operating kit's invitation/eligibility rules directly.
3. Only then, if useful, lift recruitment copy from here — re-checking each
   template against the kit, since some earlier drafts pitched the tool as
   "objective/accurate," offered free analysis as compensation, or invited
   draft-sharing, all of which violate the kit.
