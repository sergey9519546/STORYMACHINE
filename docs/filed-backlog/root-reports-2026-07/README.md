# Root session reports — filed 2026-08-04

Fifteen session-report and delivery-summary files that sat at the repo root
since the 2026-07 "V5.0 integration" era. Filed, not deleted, per the
maintainer's standing read-understand-contemplate rule and the DECISION_LOG
filed-backlog precedent.

Why filed: they document a completed (and partly retired) development phase.
The canonical current state lives in ROADMAP.md / NORTH_STAR.md /
docs/PATH_TO_DONE.md; a 2026-08-03 audit dispositioned each of these as
accurate-but-historical (the AUDIT_* set), restatement (the SESSION/EPIC/
FINAL/ULTIMATE/DELIVERY set — same 3-4 deliverables retold), or records of
dormant systems (AGENT_SCHEDULER_DELIVERY, OASIS_CINEMATIC_SUMMARY,
TRACE_TEMPORAL_SUMMARY — see the STATUS.md files beside those systems).

The one document here with unique operational value is
ULTRA_BUILD_BLUEPRINT.md: an honest post-mortem of a 13-parallel-agent
session with a 69% agent-failure rate and a root-cause breakdown of what
succeeded vs. failed in this environment. Worth reading before running
large agent fleets.

Every cross-reference among these files is internal to this directory, so
links keep resolving. MEGA_CATALOG_12700_SYSTEMS.md deliberately stays at
the root: it is externally referenced (8 files, incl.
docs/STORYTELLING_COVERAGE_MAP.md, its curated distillation) and the
maintainer designated it a coverage map worth keeping.
